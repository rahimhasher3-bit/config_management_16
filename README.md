# Эмулятор оболочки ОС

Практическая работа по дисциплине
«Конфигурационное управление».

Вариант №16.

## Общее описание

Программа представляет собой простой эмулятор командной оболочки
UNIX-подобной операционной системы.

На первом этапе реализован консольный интерфейс REPL.

## Реализованные функции

- приглашение к вводу содержит имя VFS;
- поддерживается раскрытие переменных окружения;
- реализована команда-заглушка `ls`;
- реализована команда-заглушка `cd`;
- реализована команда `exit`;
- реализована обработка неизвестных команд.

## Запуск

Для запуска в Windows:

```bash
run.bat
## Этап 2. Конфигурация

На втором этапе реализована поддержка параметров командной строки.

Поддерживаются следующие параметры:

- `--vfs` — путь к виртуальной файловой системе;
- `--script` — путь к стартовому скрипту.

При запуске программа выводит значения параметров.

Стартовый скрипт выполняет команды последовательно.
При возникновении первой ошибки выполнение скрипта останавливается.

Для проверки параметров созданы тестовые Windows-скрипты:

- `scripts/test_vfs.bat`
- `scripts/test_script.bat`
- `scripts/test_all.bat`

### Пример запуска

```bash
run.bat --vfs test_vfs.zip --script scripts/startup_test.txt
## Этап 3. VFS

На третьем этапе подключена виртуальная файловая система.

Источник VFS — ZIP-архив.

Все данные загружаются и обрабатываются в памяти без распаковки архива на диск.

Для хранения двоичных данных используется Base64.

Поддерживается файл `motd` в корне VFS.
Если файл существует, его содержимое выводится при запуске эмулятора.

Для тестирования созданы разные варианты VFS:

- `vfs_samples/test_vfs.zip` — минимальный VFS;
- `vfs_samples/multi_vfs.zip` — VFS с несколькими файлами;
- `vfs_samples/deep_vfs.zip` — VFS с тремя уровнями каталогов.

Также созданы тестовые скрипты:

- `scripts/test_min_vfs.bat`
- `scripts/test_multi_vfs.bat`
- `scripts/test_deep_vfs.bat`
- `scripts/stage3_startup.txt`

### Пример запуска

```bash
run.bat --vfs vfs_samples/deep_vfs.zip --script scripts/stage3_startup.txt
